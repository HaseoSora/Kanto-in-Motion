# Package variant: No Pokémon Assets

This is the **Kanto in Motion v1.3.0 No Pokémon Assets** package.

It excludes locally imported/generated Pokémon front/back/title artwork and the associated generated sprite metadata listed in `ASSET_NOTICES.md`. KIM's code, integrated KRS backgrounds, move-animation assets, UI assets, trainer presentation, shiny encounter cue, and local import workflow remain included.

Install only one Kanto in Motion package variant.
