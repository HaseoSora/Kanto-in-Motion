# Package variant: No Pokémon Assets

This is the **Kanto in Motion v1.3.2 No Pokémon Assets** package.

It excludes locally imported/generated Pokémon front/back/title artwork and the generated sprite metadata that directly depends on those payloads. Use `tools/import_assets.py` or your established local asset workflow to populate compatible animation assets.

Install only one Kanto in Motion package variant.
