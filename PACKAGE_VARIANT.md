# Package Variant

Kanto in Motion v1.6.3 public release package.

This is the standard slim-core KIM package. Large HD Pokémon battle sprite sheets and HD battle backgrounds remain in the separate persistent external asset pack managed by KIM's in-game HD Asset Manager.

The package includes the finalized Gen 2 Battle Art Voxel 2.1.x compatibility updates and the Gen 2 Modern UI polish described in `README.md`, `CHANGELOG.md`, and `RELEASE_NOTES.md`.
