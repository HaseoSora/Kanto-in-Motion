# Kanto in Motion v1.5.0 release

This package represents the v1.5.0 multi-generation code/documentation release state.

The public full package is expected to include the existing large Kanto in Motion HD battle/background asset folders in addition to these files. The development upload used to assemble this release intentionally omitted those large pre-existing assets because of upload-size limits.

The v1.5.0 release adds the G/S/C and FR/LG runtime paths, HD menu icons #001–386, updated public documentation, and the final mobile/desktop compatibility fixes.
