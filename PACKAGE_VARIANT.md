# Kanto in Motion v1.5.2 — Code-only release package

This package contains the complete v1.5.2 runtime code and public documentation assembled from the confirmed Gen 2 Modern UI release baseline.

The large pre-existing Kanto in Motion Pokémon/background artwork was not part of the development upload used to assemble this package, so those large asset folders are intentionally not duplicated here.

When updating an existing full-assets Kanto in Motion installation, keep the existing asset folders and replace the code/documentation files with this v1.5.2 package.
