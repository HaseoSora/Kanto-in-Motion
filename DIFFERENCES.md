# Kanto in Motion v1.5.0 scope

Compared with the v1.4.x Gen 1-focused release line, v1.5.0 expands Kanto in Motion to all three supported game families:

- Red / Blue / Yellow retain the complete KIM battle/UI stack.
- Gold / Silver / Crystal gain HD animated battle, Summary, Pokédex, and icon presentation while retaining native Gen 2 UI and battle systems.
- FireRed / LeafGreen gain HD animated battle/menu/Pokédex presentation, HD icons, and optional HD battle backgrounds while retaining native Game3 UI and move animations.
- HD Rescaled Pokémon icons #001–386 are available across all three generations.
- FR/LG desktop/mobile placement and duplicate-HUD issues are resolved.
