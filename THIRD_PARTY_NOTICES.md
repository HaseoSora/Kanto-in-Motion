## Gen1 Modern UI

Kanto in Motion v1.1.0 integrates a customized local build identified as **Gen1 Modern UI 0.9.11 – Central Mod Menu + Title Start**.

**Original project / author credit:** [ArmstrongThomas](https://github.com/ArmstrongThomas/gen1-modern-ui/commits?author=ArmstrongThomas)  
**Repository:** https://github.com/ArmstrongThomas/gen1-modern-ui

The integrated copy was adapted to run under Kanto in Motion's existing `animated_menu_pokemon` mod identity and to consume Kanto in Motion's animated sprite provider directly. Credit for the Gen1 Modern UI foundation belongs to ArmstrongThomas.

## Pokémon-derived artwork

The public Kanto in Motion package contains no Pokémon-derived sprite atlases or custom Pokémon title artwork. Players import those locally with `tools/import_assets.py`.
